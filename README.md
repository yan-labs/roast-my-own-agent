One line, 119 characters: a roast of my own AI agent — it has read the entire internet and still opens every answer with 'Great question!' like a man stalling for time.

The program writes the line to `/output/entry.txt`, byte-identical on every run.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
